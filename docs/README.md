# Geometric library project

Проект состоит из 4 файлов: circle.py, rectangle.py, square.py, triangle.py. В проекте реализованы вычисления площади и периметра для круга, прямоугольника, квадрата и треугольника. Проект выполнен на языке программирования Python с использованием системы контроля версий Git.
Для создания данного проекта был склонирован репозиторий: https://github.com/smartiqaorg/geometric_lib

## Функции из файла circle.py

### Функция area
Возвращает площадь круга.

    Параметры:
        r (int/float) : радиус круга

    Возвращаемое значение:
        area (float) : площадь круга

    Пример вызова функции:
        area(3) --> возвращает 28.274333882308138
        area(4.7) --> 69.39778171779854

### Функция perimeter
Возвращает периметр круга.

    Параметры:
        r (float) : радиус круга

    Возвращаемое значение:
        perimeter (float) : периметр круга

    Пример вызова функции:
        perimeter(3) --> возвращает 18.84955592153876
        perimeter(4.5) --> возвращает 29.530970943744055

## Функции из файла rectangle.py

### Функция area

Возвращает площадь прямоугольника.

    Параметры:
        a (int/float) : первая сторона прямоугольника
        b (int/float) : вторая сторона прямоугольника

    Возвращаемое значение:
        area (int/float) : площадь прямоугольника

    Пример вызова функции:
        area(3, 4) --> возвращает 12
        area(4.5, 8.2) --> возвращает 36.9

### Функция perimeter

Возвращает периметр прямоугольника.

    Параметры:
        a (int/float) : первая сторона прямоугольника
        b (int/float) : вторая сторона прямоугольника

    Возвращаемое значение:
        perimeter (int/float) : периметр прямоугольника

    Пример вызова функции:
        perimeter(3, 4) --> возвращает 14
        perimeter(4.5, 7.9) --> возвращает 24.8

## Функции из файла triangle.py

### Функция area

Возвращает площадь треугольника.

    Параметры:
        a (int/float) : сторона треугольника
        h (int/float) : высота треугольника

    Возвращаемое значение:
        area (int/float) : площадь треугольника

    Пример вызова функции:
        area(4, 6) --> возвращает 12
        area(2.1, 6.8) --> возвращает 7.14

### Функция perimeter
Возвращает периметр треугольника.

    Параметры:
        a (int/float) : первая сторона треугольника
        b (int/float) : вторая сторона треугольника
        c (int/float) : третья сторона треугольника

    Возвращаемое значение:
        perimeter (int/float) : периметр треугольника

    Пример вызова функции:
        perimeter(3, 4, 5) --> возвращает 12
        perimeter(3.6, 1.5, 2) --> возвращает 7.1
